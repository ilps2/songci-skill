# 公众号「官方 API 自动发布」配置与使用说明

> 配套脚本：`wechat_publish.py`
> 适用：已认证的微信公众号（服务号 / 认证订阅号），个人未认证订阅号**没有**草稿箱/发布接口权限，请改用「排版版一键粘贴」方案。

---

## 一、前置条件（缺一不可）

| 条件 | 说明 |
|---|---|
| 公众号已认证 | 微信认证（300 元/年）或企业认证；个人号无此接口权限 |
| 接口权限 | 公众号后台能查到「草稿箱」「发布能力」接口（大部分认证号默认开通） |
| 出口 IP 白名单 | 运行脚本的机器 IP 必须加入公众号 IP 白名单，否则报 `40164` |

---

## 二、配置步骤（约 3 分钟）

### 第 1 步：拿到 AppID 和 AppSecret

1. 登录公众号后台：<https://mp.weixin.qq.com>
2. 左侧菜单：**设置与开发 → 基本配置**
3. 复制 **AppID**
4. 点击 **AppSecret → 重置/生成**（**只在生成时显示一次**，立即复制保存）

> ⚠️ AppSecret 是你的账号凭据，等于"发布权限的钥匙"。**不要**发给别人、**不要**提交到代码仓库、**不要**粘贴进聊天记录。用它运行完脚本后，可在后台重置。

### 第 2 步：配置 IP 白名单

1. 还是在「基本配置」页，找到 **IP 白名单**
2. 点击修改，把**运行脚本机器的公网出口 IP** 加进去

**沙箱环境出口 IP（本次探测）**：

```
124.221.146.7
111.229.52.240
```

> ⚠️ **重要提醒**：本沙箱出口 IP 是**动态变化**的，今天能用明天可能失效。最稳妥的做法是把脚本放到**你自己有固定 IP 的服务器/电脑**上运行（配置一次白名单长期有效）。如果在沙箱跑，报 `40164` 时重新探测 IP 并更新白名单即可。

### 第 3 步：确认接口可用

公众号后台 → **设置与开发 → 接口权限**，搜索「草稿箱」「发布能力」，确认状态为"已获得"。

## 三、运行命令

### 1）只创建草稿（推荐，安全）

```bash
cd /workspace
WECHAT_APPID=你的AppID WECHAT_SECRET=你的AppSecret python3 wechat_publish.py \
  --md "从雨过天青到一张会变色的封面·公众号文章.md" \
  --cover "cover_示例.png" \
  --title "从雨过天青到一张会变色的封面" \
  --author "你的名字"
```

运行成功后，文章会出现在公众号后台 **草稿箱**，你检查排版无误后手动点「发布」——**这一步保持人工确认最稳**。

### 2）创建草稿 + 直接发布

在上一命令末尾加 `--publish` 即可直接提交发布（发布记录在后台可见）。

### 3）正文追加配图

```bash
...  --images "cover_美食.png,cover_家居.png,cover_黑釉.png"
```

把本地图片上传为正文插图（图片先放到 /workspace 下）。

### 4）自定义摘要

```bash
...  --digest "一句话摘要"
```

## 四、脚本做了什么（后台流程）

```
Markdown 文章
   │  markdown 转 HTML（标题/引用/表格自动加宋瓷风内联样式）
   ▼
上传封面图 ──► material/add_material ──► thumb_media_id（永久素材）
   ▼
上传正文配图 ──► media/uploadimg ──► 正文 <img> URL（mmbiz.qpic.cn）
   ▼
创建草稿 ──► draft/add ──► 草稿箱 media_id
   ▼
（可选）直接发布 ──► freepublish/submit ──► 发布记录
```

## 五、常见错误对照

| errcode | 含义 | 处理 |
|---|---|---|
| 40164 | 来源 IP 不在白名单 | 把当前出口 IP 加入后台 IP 白名单 |
| 48001 | 接口无权限 | 公众号未认证 / 未开通发布能力，改用排版版方案 |
| 40001 | access_token 失效 | 删除 `/tmp/wx_token.json` 重试 |
| 40125 | AppSecret 错误 | 后台重置 AppSecret |
| 40013 | AppID 错误 | 检查 AppID 是否复制完整 |
| 45009 | 接口超限 | 官方接口有频率限制，稍后再试 |
| 53010 | 内容违规 | 检查文章是否含敏感词，修改后重试 |

---

## 六、安全提醒（务必阅读）

1. **AppSecret 是最高机密**：只在运行脚本时通过环境变量传入，运行完可在后台重置。
2. **先草稿、后发布**：默认只到草稿箱，人工确认排版（尤其表格、图片）后再发布，避免翻车。
3. **沙箱 IP 不稳定**：长期自动发布请用固定 IP 环境；沙箱里每次运行前先探测 IP。
4. **接口限额**：access_token 每日调用 2000 次、素材上传有次数限制，正常发布不受影响，但别高频测试。
