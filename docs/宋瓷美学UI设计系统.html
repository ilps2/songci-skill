DESIGN PRINCIPLES

五条设计原则

宋瓷美学转译成界面设计，最终落在五条可执行的准则上。

壹

极简 · 器无赘饰

MINIMALISM

内容优先，装饰最小化。少用边框与分隔线，用留白和字重建立层级，像宋瓷一件器物只有一个视觉焦点。

贰

素雅 · 釉色为美

MUTED PALETTE

低饱和配色，全局只有一个主色（天青）。强调色只在关键动作处出现，其余界面让位于内容本身。

叁

玉感 · 温润触觉

JADE TOUCH

大圆角、柔和阴影、微透明与渐变，模拟玉的漫反射。按钮按下去像触摸一块温润的釉面，而非冷硬的玻璃。

肆

留白 · 意境呼吸

NEGATIVE SPACE

区块间距主动放大（48–96px），信息密度主动降低。留白不是浪费，是文人画里的"计白当黑"。

伍

含蓄 · 动效克制

RESTRAINT

过渡统一 300–500ms、缓出曲线、无弹跳无夸张。动效像釉色流淌一样平静，存在但不出声。

COLOR · 釉色提取

色彩系统

直接从宋瓷釉色中取值：天青、粉青、月白、豆青、象牙白、黑釉、茶褐。全部低饱和，大面积使用以月白与象牙白为主。

TYPOGRAPHY · 文人书写

字体与排版

标题用衬线体（宋体系）承接文人气质，正文用无衬线保证现代可读性。字号层级克制，最多五级。
