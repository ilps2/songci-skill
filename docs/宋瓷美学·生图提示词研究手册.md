# 宋瓷美学 · 生图/生视频提示词研究手册

> 研究主题：宋代瓷器（960-1279）的美学特征及其在 AI 生图/生视频中的提示词表达
> 核心结论：宋瓷是"可参数化"程度最高的中国古代审美——釉色、开片、窑变、器型都有明确视觉特征，非常适合拆解成 AI 听得懂的提示词词汇。

---

## 0. 为什么选宋瓷做生图研究

1. **审美天花板**：宋瓷代表中国器物美学的巅峰——"雨过天青云破处"的汝窑天青、温润如玉的龙泉青釉、神秘莫测的建窑曜变，其审美高度在艺术史上是公认的。
2. **特征可描述**：与明清瓷的繁复纹饰不同，宋瓷的美学集中在**釉色、质感、器型比例**三大维度，恰好是 AI 生图模型最擅长理解和执行的视觉要素。
3. **风格辨识度极高**：AI 模型对 "ru ware sky blue"、"jian ware hare's fur" 这类专有名词有不错的语义映射，输出稳定度远高于抽象审美描述。
4. **应用场景广**：器物还原（收藏研究）、氛围创作（侘寂风/新中式）、细节研究（釉面微距）都能复用同一套知识体系。

---

## 1. 宋瓷美学五要素（提示词总纲）

研究宋瓷，提炼出五个决定画面气质的要素，**每一条都要翻译成提示词**：

| 美学要素 | 中文要点 | 提示词翻译 |
|---|---|---|
| 极简造型 | 线条简练、比例精妙、无多余装饰 | `minimalist form, clean silhouette, elegant proportions` |
| 釉色为美 | 不靠彩绘，纯以釉色和质感取胜 | `monochrome glaze, no painted decoration` |
| 玉质追求 | "温润如玉"是最高评价标准 | `jade-like texture, soft glossy surface, warm translucent quality` |
| 含蓄内敛 | 低饱和、哑光感、静默气质 | `muted tones, subdued color, quiet understated elegance` |
| 留白意境 | 文人审美、禅意、空间感 | `negative space, literati aesthetic, zen-like stillness` |

**一句话公式：**
> 宋瓷提示词 = **窑口/釉色词 + 器型词 + 釉面特征词 + 展示场景词 + 摄影质感词**

## 2. 窑口谱系与釉色词典（核心内容）

### 2.1 汝窑 Ru Ware —— 天青之极

| 维度 | 内容 |
|---|---|
| 历史地位 | 五大名窑之首，北宋宫廷专用，传世不足百件 |
| 标志釉色 | 天青釉 sky-blue（"雨过天青云破处"），另有粉青、月白、豆青 |
| 关键特征 | 温润如玉、蝉翼纹细开片、芝麻钉支烧痕迹（香灰胎） |
| 造型 | 弦纹瓶、三足洗、水仙盆、盏托 |

**核心提示词词汇：**
```
ru ware, sky-blue glaze, jade-like texture, subtle hairline crackle,
minimalist form, sesame seed spur marks, muted pale blue
```

> ⚠️ AI 常见翻车：天青容易生成饱和艳蓝。必须加 `muted`（低饱和）、`pale`（淡雅）、`jade-like`（玉感）三个限制词。

### 2.2 官窑 Guan Ware —— 厚釉冰裂

| 维度 | 内容 |
|---|---|
| 特点 | 北宋/南宋宫廷窑，多次上釉、釉层极厚 |
| 标志釉色 | 粉青、月白、灰青、米黄 |
| 关键特征 | **冰裂纹**大开片、紫口铁足（口沿釉薄泛紫、足底露胎泛铁色） |
| 造型 | 贯耳瓶、弦纹瓶、葵口洗、鬲式炉 |

**核心提示词词汇：**
```
guan ware, thick celadon glaze, large ice-crackle pattern,
purple mouth and iron-brown foot, grey-blue glaze, aged texture
```

### 2.3 哥窑 Ge Ware —— 断纹之美（金丝铁线）

| 维度 | 内容 |
|---|---|
| 特点 | 传说中章生一、章生二兄弟窑之一，开片艺术登峰造极 |
| 标志釉色 | 青灰、米黄 |
| 关键特征 | **金丝铁线**——细密金黄色开片（金丝）+ 粗黑大开片（铁线）交错；鱼子纹、百圾碎 |
| 美学意义 | "缺陷即美学"的极致——把裂纹变成装饰 |

**核心提示词词汇：**
```
ge ware, crackled glaze, golden thread and black iron-wire crackle lines,
fine fish-roe crazing, warm grey glaze, antique patina
```

### 2.4 钧窑 Jun Ware —— 窑变天成

| 维度 | 内容 |
|---|---|
| 特点 | 五大名窑中唯一不以釉色纯正为追求的——"入窑一色，出窑万彩" |
| 标志釉色 | 天蓝、月白，及窑变产生的**玫瑰紫、海棠红**、红斑 |
| 关键特征 | 窑变效果 kiln transmutation、蚯蚓走泥纹 |
| 造型 | 花盆、尊、洗、瓶 |

**核心提示词词汇：**
```
jun ware, kiln transmutation glaze, rose-purple and sky-blue mottled,
splash of crimson, flowing glaze texture, opalescent effect
```

### 2.5 定窑 Ding Ware —— 白瓷刻花

| 维度 | 内容 |
|---|---|
| 特点 | 唯一以白瓷入列五大名窑；工艺上首创覆烧，产生"芒口"（口沿无釉） |
| 标志釉色 | 象牙白 ivory-white |
| 关键特征 | 刻花、划花、印花（莲纹、牡丹纹）；口沿常包金银铜边 |
| 造型 | 孩儿枕、净瓶、盏、盘 |

**核心提示词词汇：**
```
ding ware, ivory-white porcelain, incised lotus decoration,
fine carved lines, unglazed rim, warm white tone
```

### 2.6 龙泉窑 Longquan Celadon —— 青瓷巅峰

| 维度 | 内容 |
|---|---|
| 特点 | 南宋龙泉为青瓷史巅峰，釉厚如脂、莹润如玉 |
| 标志釉色 | **粉青 powder-blue**、**梅子青 plum-green**（两大名釉） |
| 关键特征 | 厚釉肥润、开片少或无开片、露胎处火石红 |
| 造型 | 梅瓶、凤耳瓶、鬲式炉、贯耳瓶、纸槌瓶 |

**核心提示词词汇：**
```
longquan celadon, powder-blue glaze, jade-like glossy surface,
thick creamy glaze, plum-green tint, kiln-fired stoneware
```

### 2.7 建窑 Jian Ware —— 黑釉茶盏（斗茶神器）

| 维度 | 内容 |
|---|---|
| 特点 | 宋代点茶/斗茶文化核心器具，黑釉上的微观宇宙 |
| 标志釉色 | 黑釉 black glaze |
| 关键特征 | **兔毫 hare's fur**（丝状结晶纹）、**油滴 oil spot**（银白斑点）、**曜变 yohen**（蓝紫虹彩，传世仅 3 件）、鹧鸪斑 |
| 造型 | 束口盏、撇口盏、斗笠盏（conical tea bowl） |

**核心提示词词汇：**
```
jian ware tea bowl, black glaze, hare's fur streaks,
metallic blue sheen, radial striations, ceramic tea bowl

// 曜变版（最强稀有度）：
jian ware, yohen kiln-change, iridescent blue and purple
galaxy-like spots on black glaze, rainbow oil-spot reflections
```

### 2.8 磁州窑 Cizhou / 耀州窑 Yaozhou —— 民间烟火

| 窑口 | 特征 | 提示词词汇 |
|---|---|---|
| 磁州窑 | 白地黑花（白化妆土+黑彩绘画/书法）、民窑生活气 | `cizhou ware, white slip with black painted decoration, bold brushwork, folk art` |
| 耀州窑 | 刻花青瓷、橄榄绿、刀法犀利（半刀泥） | `yaozhou ware, carved celadon, olive-green glaze, sharp incised relief` |

## 3. 器型词典（Form Vocabulary）

| 器型 | 英文 | 画面特征 |
|---|---|---|
| 梅瓶 | meiping (plum vase) | 小口、短颈、丰肩、瘦胫——宋代器型之冠 |
| 玉壶春瓶 | yuhuchun (pear-shaped vase) | 撇口、细颈、垂腹，曲线优雅 |
| 弦纹瓶 | vase with raised bow-string lines | 颈部几道凸起弦纹，极简典范 |
| 贯耳瓶 | vase with tubular handles | 颈部两侧贯耳，官窑经典 |
| 凤耳瓶 | phoenix-handled vase | 龙泉经典，双耳似凤尾 |
| 纸槌瓶 | mallet vase | 直口、长颈、折肩，几何感强 |
| 胆瓶 | gall-bladder vase | 颈细腹圆，如悬胆 |
| 三足洗/笔洗 | tripod brush washer | 文房器物，汝窑经典 |
| 葵口盘/洗 | dish with mallow-form rim | 口沿呈花瓣形 |
| 茶盏 | tea bowl | 建盏多为束口/斗笠形 |
| 香炉（鬲式炉） | li-style incense burner | 三足、腹部出筋，龙泉经典 |
| 孩儿枕 | child-shaped pillow | 定窑名品，趣味性 |

**提示词技巧：** 器型词直接决定造型比例。写 `meiping` 或 `pear-shaped vase`，模型会调用见过的同类器型数据，比写"一个好看的瓶子"精准十倍。

## 5. 展示场景与摄影语法（Presentation Vocabulary）

宋瓷器物本身极简，**场景决定画面气质**。三套场景语法：

### A. 博物馆展陈（研究还原向）
```
museum display, soft spotlight, dark or neutral background,
subtle shadow, object photography, archival lighting, 8k
```

### B. 文人氛围（美学创作向）
```
literati study setting, tea ceremony scene, bamboo mat, wooden table,
warm side light, wabi-sabi atmosphere, film still, cinematic
```

### C. 细节微距（纹理研究向）
```
macro photography, extreme close-up on glaze surface,
crackle texture detail, raking light to reveal texture,
fine art photography
```

**光影黄金法则**（宋瓷拍摄/生成通用）：
- 侧光/侧逆光最能表现釉面质感和开片纹理（`raking light`、`side light`）
- 柔光适合表现"温润如玉"（`soft diffused light`）
- 避免正面平光——会把釉面拍"平"，失去玉质感（可用负面词排除）

## 6. 提示词模板（宋瓷专用）

### 生图模板（按权重排序）
```
[窑口+釉色] + [器型] + [釉面特征] + [场景] + [光线] + [摄影质感] + [画质词]
```

### 完整结构示例
```
ru ware sky-blue porcelain vase, meiping form, jade-like glaze,
subtle hairline crackle, displayed in a dim museum hall,
soft spotlight from above, gentle shadow, minimal background,
product photography, photorealistic, 8k
```

## 8. 常见翻车与避坑策略

| 翻车现象 | 原因 | 对策 |
|---|---|---|
| 天青釉变成艳蓝 | 模型默认"蓝=饱和" | 加 `muted` `pale` `jade-like`，或用负面词排除 `vivid blue` |
| 变成明清彩瓷 | 模型把"中国瓷器"关联到五彩/粉彩 | 强调 `monochrome glaze, no painted decoration` |
| 开片变成密集网格 | 开片词权重过高 | 用 `subtle` `hairline` 限制，或写 `sparse crackle` |
| 兔毫过于花哨 | 特征词堆叠过度 | 单一特征 + `delicate` `fine`，避免同时写兔毫+油滴 |
| 釉面发"塑料感" | 缺少质感词 | 必加 `jade-like` `matte` `glossy` 之一，配合 `ceramic texture` |
| 场景喧宾夺主 | 场景词过强 | 器身大于画面 60% 以上：`large object in frame` |

**宋瓷通用负面提示词（可复制）：**
```
negative: vivid colors, painted floral decoration, glossy plastic look,
busy background, cluttered scene, watermark, text, modern style
```

## 9. 生视频进阶（宋瓷动态表达）

| 手法 | 提示词写法 | 表达效果 |
|---|---|---|
| 旋转展示 | `camera orbits 360° around the vase, slow smooth rotation` | 全貌鉴赏，博物馆感 |
| 微距推镜 | `camera slowly dollies in on the glaze surface, macro detail` | 揭示开片/兔毫纹理 |
| 茶水入盏 | `hot tea being poured into the jian bowl, steam rising, camera tilts down` | 茶文化叙事 |
| 光影流动 | `soft light moving across the celadon surface, subtle reflections` | 釉面质感之美 |
| 窑变幻化（艺术化） | `glaze colors slowly transforming from blue to purple, surreal` | 钧窑美学意象 |
