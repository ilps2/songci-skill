# 电影运镜 · 生图/生视频提示词速查手册

> 目标：把导演的镜头语言，翻译成 AI 听得懂的提示词。
> 适用：Midjourney / Stable Diffusion / DALL·E / Sora / Veo / Runway / 可灵 / 即梦 等生图、生视频工具。

---

## 0. 核心理念：提示词的三层结构

一份好提示词 = **镜头语言（骨架） + 画面内容（血肉） + 质感风格（气质）**。

大多数人的提示词只有第二层（描述"拍什么"），而镜头语言（"怎么拍"）才是决定作品上限的关键。

```
[景别] + [机位角度] + [焦段/光学] + [主体与动作] + [环境] + [光线] + [色调风格] + [画质词]
```

本手册按"从骨架到气质"的顺序展开：**景别 → 机位 → 运镜 → 光学 → 构图 → 光线 → 提示词模板 → 进阶技巧**。

---

## 1. 景别（Shot Size）——控制信息量与叙事重点

景别决定观众"看到多少、离多近"，是生图提示词里**优先级最高**的词汇，直接决定主体在画面中的占比。

| 景别 | 英文关键词 | 画面内容 | 叙事功能 | 提示词示例 |
|---|---|---|---|---|
| 大远景 | extreme long shot / establishing shot | 环境为主，人物极小 | 交代时空、史诗感 | `extreme wide shot, tiny figure in vast landscape` |
| 远景 | wide shot / long shot | 全身 + 大量环境 | 动作与环境的平衡 | `wide shot, full body, showing the surroundings` |
| 全景 | full shot | 全身，环境较少 | 展示动作姿态 | `full body shot` |
| 中景 | medium shot | 腰部以上 | 对话、叙事主力 | `medium shot` |
| 中近景 | medium close-up | 胸部以上 | 情绪与表演 | `medium close-up` |
| 特写 | close-up | 面部 | 情绪、注意力聚焦 | `close-up on her face` |
| 大特写 | extreme close-up | 眼睛、手、局部细节 | 强视觉冲击、象征 | `extreme close-up on the eyes` |

**提示词要点：**
- 景别词放在提示词**开头**，模型对句首信息权重最高。
- 情绪/细节越重要，景别越近（叙事递增：大远景 → 特写）。
- 生视频中，景别变化可以通过运镜实现（如 `medium shot slowly push to close-up`）。

---

## 2. 机位角度（Camera Angle）——控制情绪与权力关系

同样的内容，换个机位就是完全不同的情绪。角度词是**情绪的快捷键**。

| 角度 | 英文关键词 | 画面效果 | 情绪/暗示 | 适用场景 |
|---|---|---|---|---|
| 平视 | eye level | 中性客观，代入感强 | 平等、真实、纪录片感 | 人物访谈、日常叙事 |
| 低角度仰拍 | low angle | 主体高大，背景干净 | 力量、威严、英雄感、压迫感 | 英雄登场、建筑仰视 |
| 高角度俯拍 | high angle | 主体渺小 | 弱势、孤独、命运感 | 危机时刻、童年视角 |
| 顶拍 | overhead / bird's-eye view / top-down | 正上方俯视 | 上帝视角、图案化、宿命 | 餐桌、棋局、城市夜景 |
| 斜角/荷兰角 | dutch angle / tilted | 画面倾斜，地平线歪 | 失衡、不安、惊悚 | 悬疑、心理戏 |
| 过肩镜头 | over-the-shoulder (OTS) | 前景肩膀，对面主体 | 对话关系、窥视感 | 双人对话 |
| 主观镜头 | POV / point-of-view | 模拟角色眼睛 | 第一人称沉浸 | 恐怖片、冒险片 |

**提示词要点：**
- 角度词 + 景别词组合使用：`low angle close-up`（仰拍特写）、`high angle wide shot`（俯拍远景）。
- 想让主体"有压迫感"→ 低角度；想让主体"被环境吞噬"→ 高角度 + 大远景。

## 3. 镜头运动（Camera Movement）——生视频的核心维度

生视频模型对运镜指令有直接执行力，运镜词是**生视频提示词里最值钱的部分**。生图虽无运动，但"暗示运动"的词汇（如 motion blur、whip pan）也能增加动感。

### 3.1 基础运镜

| 运镜 | 英文关键词 | 运动方式 | 情绪功能 |
|---|---|---|---|
| 推 | dolly in / push in | 机位向主体直线前进 | 深入内心、强调、紧张感递增 |
| 拉 | dolly out / pull back | 机位远离主体 | 揭示环境、孤独感、落幕感 |
| 摇 | pan (left/right) | 机位不动，镜头水平转动 | 展示空间关系、转移注意力 |
| 俯仰摇 | tilt (up/down) | 机位不动，镜头垂直转动 | 揭示全貌、由细节到全局 |
| 横移 | track / truck (left/right) | 机位水平平行移动 | 伴随感、稳定叙事、情绪推进 |
| 升降 | crane up/down / jib | 机位垂直升降 | 史诗感、俯瞰全局、结尾升华 |
| 跟拍 | follow shot | 机位跟着主体走 | 沉浸跟随、动态展示 |
| 环绕 | orbit / arc / 360° | 绕主体圆周运动 | 突出主角、仪式感、空间全览 |
| 手持 | handheld | 轻微晃动 | 纪实、紧张、混乱、临场感 |
| 稳定器 | steadicam / gimbal shot | 平稳跟随 | 丝滑优雅、流畅运动 |
| 变焦 | zoom in/out | 镜头内部缩放（机位不动） | 快速强调、注意聚焦 |
| 甩镜 | whip pan | 镜头快速横扫 | 转场、节奏、能量释放 |
| 希区柯克变焦 | dolly zoom / vertigo effect | 推拉+变焦同步 | 眩晕、心理失衡、压迫感 |

> **推镜 ≠ 变焦**：推（dolly）是机位物理移动，透视随距离变化；变焦（zoom）是镜头内部缩放，透视压缩感强。写提示词时区分使用，效果差异明显。

### 3.2 运镜修饰词（关键技巧）

运镜词 + 修饰词 = 精确控制运动质感：

| 维度 | 修饰词 | 效果 |
|---|---|---|
| 速度 | slowly / slow, rapidly / fast, quick, gentle | 缓慢=诗意沉稳，快速=紧张冲击 |
| 平滑度 | smooth, steady, shaky, handheld feel | 平滑=专业质感，晃动=纪实感 |
| 幅度 | subtle, slight, dramatic | 微运镜=氛围，大幅度=表现力 |

**示例：**
```
slowly dollies in      → 缓慢推进，情绪沉淀
rapid handheld push    → 急促前冲，纪实冲击
smooth 360° orbit      → 丝滑环绕，主角仪式感
subtle steadicam drift → 轻微漂移，呼吸感
```

### 3.3 运镜的组合与节奏

- 一段视频可以用复合运镜：`dolly in while panning left`（推+摇复合）。
- 单次运镜聚焦一个方向最稳：**一个镜头一个运镜**，避免模型混淆。
- 运镜方向建议写清：`pan left`、`tilt up`、`crane down`，减少模型随机性。

## 4. 光学与镜头特性（Lens & Optics）——画质的物理基础

光学词直接决定画面的"质感档位"，让出图立刻有摄影感而非"画出来"的感觉。

| 维度 | 英文关键词 | 效果 |
|---|---|---|
| 广角 | wide-angle lens / 16-24mm | 透视夸张、空间纵深、边缘畸变 |
| 标准 | 35mm / 50mm lens | 接近人眼视角，真实自然 |
| 长焦 | telephoto / 85mm / 135mm | 空间压缩、背景拉近、人像首选 |
| 微距 | macro lens | 极端特写、细节纹理 |
| 大光圈 | f/1.4, f/1.8, shallow depth of field | 浅景深、背景奶油虚化（bokeh） |
| 深景深 | deep focus / f/8 | 前后景都清晰、纪实感 |
| 慢快门 | long exposure, motion blur | 运动拖影、流光、时间流逝 |
| 变形宽银幕 | anamorphic lens | 2.35:1 宽幅、椭圆光斑、横纹眩光、电影感拉满 |
| 镜头光晕 | lens flare | 逆光光斑、梦幻、史诗 |
| 胶片颗粒 | film grain | 复古质感、电影胶片感 |
| 暗角 | vignette | 四角压暗、聚焦中心 |
| 色差 | chromatic aberration | 边缘紫边、复古胶片味 |

**提示词要点：**
- 写"什么镜头拍的"（shot on 85mm lens）比写"清晰的"（clear）有效得多——后者模型无感，前者直接锁定透视与景深。
- 人像标准套餐：`85mm, f/1.4, shallow depth of field`。
- 史诗大场景套餐：`24mm wide angle, anamorphic, deep focus`。

## 5. 构图法则（Composition）——静态画面的视觉秩序

构图词让画面"有设计感"，是生图提示词的进阶加分项。

| 法则 | 英文关键词 | 效果 |
|---|---|---|
| 三分法 | rule of thirds | 主体放三分线上，自然耐看 |
| 中心构图 | centered composition | 对称、庄重、主角感 |
| 对称构图 | symmetrical | 秩序、仪式、建筑感 |
| 框架构图 | framing (door frame, window, arch) | 画面内有框，层次与窥视感 |
| 引导线 | leading lines | 视线被引向主体 |
| 负空间 | negative space | 大量留白、极简、孤独感 |
| 黄金分割 | golden ratio | 经典美学比例 |
| 前景虚化 | foreground bokeh | 景深感、临场感、氛围 |

**提示词示例：**
```
rule of thirds, subject on the left third, negative space on the right
centered symmetrical composition, mirror reflection
shot through a window frame, framing, foreground bokeh
```

## 6. 光线与色彩（Lighting & Color）——氛围的最终决定者

| 类型 | 英文关键词 | 效果 |
|---|---|---|
| 电影布光 | cinematic lighting | 通用氛围词，配合具体光源使用 |
| 伦勃朗光 | Rembrandt lighting | 面部三角光区，古典油画感 |
| 轮廓光/逆光 | rim light / backlight | 勾勒轮廓、发丝光、剪影 |
| 硬光 | hard light | 明暗分明、戏剧性、硬朗 |
| 软光 | soft light / diffused | 柔和、温柔、梦幻 |
| 剪影 | silhouette | 纯轮廓、神秘、日落标配 |
| 黄金时刻 | golden hour | 日落前低角度暖光，自带氛围 |
| 蓝调时刻 | blue hour | 日落后冷蓝调，静谧忧郁 |
| 霓虹光 | neon lighting | 赛博朋克、都市夜色 |
| 高调光 | high-key | 明亮通透、清新、广告感 |
| 低调光 | low-key | 大面积阴影、神秘、悬疑 |

**色调（color grade）：**
- 青橙对比 `teal and orange` —— 好莱坞商业片标配
- 低饱和 `desaturated / muted tones` —— 文艺、纪实
- 冷暖对比 `warm and cool contrast` —— 层次丰富
- 单色 `monochrome` —— 黑白经典

## 7. 提示词实战模板

### 7.1 生图模板（按权重排序）

```
[景别], [机位角度], [焦段/光圈], [主体+动作+服装], [环境], [光线], [色调], [画质词]
```

**示例一 · 电影感人物（氛围向）**
```
close-up, eye level, 85mm lens, f/1.8, shallow depth of field,
a weathered fisherman lighting his pipe, rain-soaked coat,
fishing boat at dusk, rim light, golden hour glow,
teal and orange grade, film grain, cinematic still
```

**示例二 · 史诗大场景**
```
extreme wide shot, low angle, 24mm wide angle lens, deep focus,
a lone rider crossing a vast desert dune, dust trails in the wind,
golden hour, anamorphic lens flare, epic scale,
shot on ARRI Alexa, 8k
```

**示例三 · 极简广告**
```
high-key, centered composition, 50mm lens, soft diffused light,
a minimalist perfume bottle on wet stone, water droplets,
pure white background, lots of negative space,
studio product photography, sharp focus, 8k
```

### 7.2 生视频模板

```
[主体+动作] + [镜头运动+速度+平滑度] + [环境] + [光线] + [风格] + [画质]
```

**示例一 · 情绪推进**
```
A woman looks out a rainy window, camera slowly dollies in
from medium shot to close-up, steadicam, smooth motion,
soft window light, melancholic mood, cinematic color grade, 4k
```

**示例二 · 都市能量**
```
Cyclist weaves through neon-lit Tokyo intersection at night,
rapid handheld tracking shot, motion blur on passing cars,
neon lighting, rain reflections, gritty cinematic style
```

**示例三 · 揭晓时刻**
```
A hidden castle emerges from fog, camera tilts up and pulls back
to reveal the full valley, crane shot, slow majestic movement,
misty morning light, epic fantasy atmosphere
```

**示例四 · 主角仪式感**
```
A dancer spins under a single spotlight, camera orbits 360° around
her, smooth gimbal shot, dark stage, rim light,
dramatic low-key lighting, elegant choreography
```

## 8. 常见错误与进阶技巧

### 8.1 五个常见错误

| 错误 | 问题 | 修正 |
|---|---|---|
| 只堆形容词 | `beautiful, amazing, stunning` 模型无具体指令 | 换成镜头词：`cinematic close-up, 85mm, golden hour` |
| 景别缺失 | 主体大小随机，构图不可控 | 句首必写景别 |
| 运镜与动作矛盾 | `fast dolly in` + 主体也乱动，画面混乱 | 一次只让一个东西"动"（镜头或主体） |
| 一个镜头多个运镜 | `pan and tilt and zoom and orbit` 模型难以执行 | 单一运镜 + 修饰词 |
| 中英混用混乱 | 关键词权重被稀释 | 核心镜头词保持英文，注释用中文 |

### 8.2 进阶技巧

1. **关键词前置**：模型对句首词权重最高，把景别/机位/运镜放最前面。
2. **运镜单独成句**：生视频时把运镜写成独立短句（`camera slowly dollies in`），比混在长句里识别率高。
3. **画质词收尾**：`cinematic still / film still / shot on ARRI / 8k` 放结尾统一提质感。
4. **分镜序列**：多镜头可用 `shot 1: ... shot 2: ...` 分段描述，长视频分镜比一段长文可靠。
5. **镜头内动作 vs 镜头运动**：主体动作用动词，镜头运动用 `camera + 运镜词`，二者分开写，模型不易混淆。
6. **模型差异化**：Sora/Veo 对复合运镜理解强；部分模型对 `dolly` 与 `zoom` 区分弱，出片后迭代微调即可；生图模型更吃"景别+角度+焦段"，生视频更吃"运镜动词+速度"。

## 10. 一句话总结

> **景别定信息，机位定情绪，运镜定节奏，焦段定质感，光线定氛围。**
> 写提示词 = 当导演：先把镜头参数说清楚，再描述画面内容。

**建议练习路径（30 天）：**
1. 第 1-7 天：拉片练习——看电影暂停时回答"景别？机位？镜头动没动？"，对照本手册记录。
2. 第 8-15 天：用本手册的模板改写 10 条你过往的提示词，对比出图效果。
3. 第 16-23 天：每种运镜各生成 3 条视频提示词，测试模型执行度并记录差异。
4. 第 24-30 天：建立自己的"镜头词库"，按题材（人物/风景/广告/科幻）分类整理，形成肌肉记忆。
