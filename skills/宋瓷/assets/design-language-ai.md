# 天青 Design Language · AI 速查卡

> 用途：AI 需要按"宋瓷 / 天青"美学输出 UI、品牌、图表、暗色模式时，先读本文件。
> 本文件是规则速查；机器值在 `tokens.css` / `tokens.json`（Style Dictionary / Figma Tokens 兼容），参考实现见 `demo/index.html`。

## 一句话定位

从宋代瓷器美学提取的 UI 设计语言：主色唯一（汝窑天青），一色一窑，每个色值皆有窑口出处；克制的装饰、温润的形态、克制的动效。

## 使用公式

```
UI = 色(釉色为美) + 形(温润如玉) + 留白(计白当黑) + 动效(动若釉流)，总则：器无赘饰
```

## 色彩规则（最高优先级）

### 主色（唯一）：天青，10 阶

| 阶 | 值 | 用途 |
|---|---|---|
| 50–100 | #F0F6F8 / #DCECEF | 浅底、器影 |
| 200–300 | #B9CFD9 / #9FB9C6 | 辅助；暗色模式主色（300） |
| 400–500 | #8CAEBD / #7FA8B8 | 全局主色（500） |
| 600–700 | #648C9E / #4E7486 | Hover/强调 |
| 800–900 | #3E5F6E / #2C4550 | 深底、暗色按钮文字 |

### 语义色

| 用途 | 色值 | 出处 |
|---|---|---|
| 次强调（粉青） | #B5CFC8 | 龙泉 |
| 成功（豆青） | #5C7A52 | 耀州 |
| 警示/点缀（茶褐） | #A47C48 | 茶席 |
| 错误（窑变赭） | #A65E44 | 钧窑 |

### 中性色

| 用途 | 色值 | 出处 |
|---|---|---|
| 表面（象牙白） | #F7F4EC | 定窑 |
| 背景（月白） | #EEF1F3 | 官窑 |
| 边框（汝釉） | #E5E0D4 | 汝窑 |
| 弱化（灰陶） | #8A8478 | — |
| 次文字（墨） | #4A453D | — |
| 主文字（黑釉） | #22201C | 建窑 |

### 占比与禁则

- 大面积只用：月白（底）/ 象牙白（表面）/ 黑釉（暗色底）
- 天青占比 <15%；茶褐 <5%；粉青不与天青同时大面积
- **禁用**：纯黑 `#000`、纯白 `#FFF`（大面积背景）
- **对比度（WCAG AA）**：正文 ≥4.5:1；次级/装饰 ≥3:1
  - 黑釉字在月白/象牙白上 ≈14:1（达标）
  - **天青 500 底上不要用白字**（仅 2.56:1，不达标）→ 用黑釉字（6.35:1）
  - 暗色模式按钮：底为 primary-300，字用 primary-900 #2C4550（4.93:1）；白字仅 2.05:1 禁用
  - 灰陶 #8A8478 仅限 caption/装饰（3.28:1）

## 形状与排版

| 项 | 值 |
|---|---|
| 标题字体 | `'Noto Serif SC','Songti SC','STSong',serif`，600 字重，字距 0.05–0.12em |
| 正文字体 | `'Noto Sans SC','PingFang SC',sans-serif`，行高 ≥1.7 |
| 字号阶梯 | display 40 / h1 30 / h2 22 / h3 17 / body 15 / caption 12 |
| 圆角 | sm 8 / md 14 / lg 22 / full 999；**禁 <6px** |
| 阴影 | 漫反射玉感，带天青冷灰，**禁纯黑投影** |
| 间距 | 4/8/16/24/40/64/96；区块间距 ≥40px；单屏视觉焦点 ≤3 |
| 动效 | fast 200 / base 350 / slow 500ms 缓出；禁弹跳/旋转/闪烁；位移 ≤16px、缩放 ≤1.03 |

| 组件 | 要点 |
|---|---|
| 按钮 Primary | 天青 500 底 + 白字 + full 圆角 + 天青柔影；hover 600；禁用：汝釉底 + 灰陶字 |
| 按钮 Ghost | 透明 + 天青 600 字 + 1px 天青 200 描边 |

| 标签 | 语义色 14% 透明底 + 500/600 字 + full 圆角 + caption 字号 |
| 输入框 | 象牙白底 + 汝釉边框 + 14px 圆角；聚焦：天青边 + 4px 天青光晕 |
| 导航 | 激活天青 600 字 + 2px 天青下划线；背景 92% 透明 + blur |
| 图表 | 主序列天青 500/700，次序列粉青/豆青，第三序列茶褐/窑变赭；网格极淡；**无 3D、无渐变柱** |

## 暗色模式（黑釉主题）

- 底 `#17150F`、表面 `#221F18`、边框 `#3A352B`、文字 `#EDE8DC`、次文字 `#B8B0A0`
- 主色提亮：primary-500 → primary-300；深阶（700/900）保持可用
- 阴影用黑釉色系 `rgba(23,21,15,…)`，**不用纯黑 `rgba(0,0,0,…)`**
- 按钮：字色改 primary-900（见对比度规则）

## 禁止清单

1. 禁纯黑 #000 / 纯白 #FFF（大面积）
2. 禁 <6px 直角、禁斜体、禁下划线装饰正文
3. 禁纯黑投影、禁弹跳动效、禁图表渐变柱/3D
4. 禁天青大面积（>15%）、禁粉青与天青同屏大面积
5. 禁天青底白字按钮（对比度不达标）
6. 装饰纹理（开片纹等）透明度 ≤8%，"若有若无"

## 输出规范

- UI 交付优先：可运行 HTML/CSS（引用 tokens.css）或 tokens 文件
- 每个色值附窑口出处，让用户理解决策依据
- 保持克制：信息密度低、装饰少、留白足
