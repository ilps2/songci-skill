# 天青 UI 设计语言 · 完整规范速查（Skill Asset）

## 五原则

| # | 原则 | 落地要点 |
|---|---|---|
| 1 | 器无赘饰（极简） | 装饰最少化；用留白/字重/色相分层，优先于边框 |
| 2 | 釉色为美（素雅） | 低饱和；主色仅天青 1 个；大面积强调 ≤1 处/屏 |
| 3 | 温润如玉（玉感） | 圆角 ≥6px；漫反射阴影；微透明渐变；禁硬边/纯黑投影 |
| 4 | 计白当黑（留白） | 区块间距 ≥40px；单屏视觉焦点 ≤3 个 |
| 5 | 动若釉流（含蓄） | 200–500ms 缓出；禁弹跳/旋转/闪烁 |

## 字体排版

- 标题：衬线 `'Noto Serif SC','Songti SC','STSong',serif`，600 字重，字距 0.05–0.12em
- 正文：无衬线 `'Noto Sans SC','PingFang SC','Microsoft YaHei',sans-serif`，行高 ≥1.7
- 阶梯：display 40 / h1 30 / h2 22 / h3 17 / body 15 / caption 12
- 禁：斜体、>800 字重、下划线装饰

## 组件要点

| 组件 | 规范 |
|---|---|
| 按钮 Primary | 天青 500 底 + 白字 + full 圆角 + `0 4px 14px rgba(127,168,184,.35)`；hover 600 + 上浮 1px；禁用汝釉底灰陶字 |
| 按钮 Ghost | 透明 + 天青 600 字 + 1px 天青 200 描边；hover 8% 天青底 |
| 卡片 | 象牙白 + 22px 圆角 + soft 阴影 + 24px 内边距；hover lift + 上浮 4px |
| 标签 | 语义色 14% 透明底 + 500/600 字 + full 圆角 + caption 字号 |
| 输入框 | `#FFFDF7` 底 + 汝釉边框 + 14px 圆角；聚焦天青边 + `0 0 0 4px rgba(127,168,184,.15)` |
| 导航 | 激活天青 600 字 + 2px 天青下划线；背景 92% 微透明 + 模糊 |
| 图表 | 主序列天青 500/700；次序列粉青/豆青；第三序列茶褐/窑变赭；网格 `rgba(229,224,212,.6)`；无 3D 无渐变柱 |

## 使用规则

1. 大面积只用：月白（底）/ 象牙白（表面）/ 黑釉（暗色底）
2. 天青占比 <15%；茶褐 <5%；粉青不与天青同时大面积
3. 禁纯黑 `#000` 与纯白 `#FFF`
4. 纹理（开片纹背景等）透明度 ≤8%，"若有若无"
5. 图标：单色线稿、1.5px 圆角描边、不用实心/渐变/双色
