# 宋瓷风 · 小红书封面设计手册

> 配套工具：`templates/宋瓷风小红书封面生成器.html`
> 本文档回答三个问题：小红书封面要什么？宋瓷风怎么做？批量怎么生产？

---

## 一、平台硬规范（2026 现行）

| 项目 | 规范 | 说明 |
|---|---|---|
| 首选比例 | **3:4 竖版**（1080×1440 或 1242×1656） | 信息流展示面积最大，点击率最高 |
| 次要比例 | 1:1 方图（1080×1080） | 干货合集、产品正面、头像感封面 |
| 慎用比例 | 4:3 / 16:9 横版 | 信息流被大幅裁切，仅宽幅风景可考虑 |
| 视频封面 | 9:16（1080×1920） | Vlog/口播封面 |
| 安全区 | 四边留 6%–10% | 关键文字不贴边，防系统 UI 与裁切 |
| 底部盲区 | 底部 15% | 会被点赞/收藏图标与笔记标题遮挡，不放关键信息 |
| 文字占比 | ≤ 画面 30% | 文字过多被判"广告"限流 |
| 标题字数 | ≤ 15 字（含数字） | 信息流缩略图中可读完 |
| 文件 | JPG/PNG，≤ 10MB，建议 1–2MB | |
| 禁区 | 二维码、联系方式、极限词、盗图、平台 LOGO | |

**高点击封面公式**（艾米视觉 5000+ 笔记经验）：
对比型（前后对比）· 数字型（"3 步搞定"）· 场景型（真实使用场景）· 人物型（真人出镜，面部占画面 1/3）。

## 二、封面类型学 → 宋瓷布局映射

| 类型 | 典型内容 | 生成器布局 | 关键设计 |
|---|---|---|---|
| 语录/观点 | 金句、情感、读书 | `quote` 大字语录 | 一行大标题撑场，≤12 字 |
| 日常图文 | 好物、家居、穿搭、美食 | `photo` 图文卡 | 图占 60% 高度，标题 2 行内 |
| 杂志感 | 设计分享、人物故事 | `magazine` 杂志分栏 | 左图右文，竖排标签 |
| 清单/攻略 | 干货合集、路线、清单 | `list` 清单攻略 | 数字序号徽章，3–6 条 |
| 步骤教程 | 教程、健身、食谱 | `steps` 步骤教程 | 步骤章+小图，3 步最佳 |
| 对比 PK | 横评、选择困难 | `compare` 对比双栏 | 左右对称+中央 VS 章 |
| 拼图合集 | 年度图集、多图种草 | `collage` 拼图九宫 | 3×3 网格，统一调色 |
| 测评评分 | 横评、美妆、数码 | `score` 测评评分 | 大分数+维度釉色条 |
| 海报大片 | 风景、活动、招募 | `poster` 全图海报 | 全图+底部渐变遮罩 |

## 三、宋瓷风封面设计规范

### 1. 色板（一色一窑，与天青 Design Language 同源）

| 变量 | 色值 | 出处 | 封面用途 |
|---|---|---|---|
| `--primary` | `#7FA8B8` | 汝窑天青 | 主色、徽章、色条 |
| `--deep` | `#648C9E` | 深天青 | 强调、Hover |
| `--accent` | `#A47C48` | 茶褐 | 标签、印章描边、点缀 |
| `--bg1/2` | `#F4F7F8→#E7EEF1` | 月白 | 画布底 |
| `--surface` | `#F7F4EC` | 象牙白 | 卡片面 |
| `--ink` | `#22201C` | 黑釉 | 主文字 |
| `--ink2` | `#4A453D` | 墨陶 | 次文字 |
| 禁色 | 纯黑 #000 / 纯白 #FFF / 高饱和艳色 | | 宋瓷克制原则 |

### 2. 字号阶梯（3:4 竖版，画布宽 1080px 折算）

| 层级 | 显示值（宽 380px 画布） | 输出值（1080px） | 用途 |
|---|---|---|---|
| 大标题 | 2.6em ≈ 48px | ≈ 136px | quote 布局主标题 |
| 中标题 | 1.8em ≈ 33px | ≈ 95px | photo/list 标题 |
| 小标题 | 1.35em ≈ 25px | ≈ 70px | 条目名/步骤名 |
| 正文 | 0.72em ≈ 13.5px | ≈ 38px | caption |
| 标签/页脚 | 0.6em ≈ 11px | ≈ 31px | tag/brand/tags |

规则：标题用宋体（Songti SC / SimSun serif），正文用 PingFang / 黑体 sans；**信息流缩略图（约 200px 宽）下标题仍须可读** → 标题不低于 1.5em。

### 3. 装饰元素（克制使用，同时出现 ≤ 2 类）

- **开片纹**：极淡 crackle SVG 曲线，`rgba(34,32,28,.05)`，黑釉主题反白
- **双线框**：外框主色 3px + 内线 accent 1px，四角菱形节点
- **印章**：宋体单字方形章，主色底白字，40×40
- **釉色带**：6 枚釉色圆点横条，作色板签名
- 原则：装饰若有若无，不与标题抢视线。

### 4. 品类 × 主题映射

| 品类 | 推荐主题 | 原因 |
|---|---|---|
| 知识/读书/职场 | 汝窑天青 | 冷静可信 |
| 家居/手作/茶 | 定窑象牙 | 温暖日常 |
| 风景/旅行 | 龙泉粉青 | 自然清透 |
| 美妆/时尚 | 钧窑窑变（赭色点缀） | 有冲击不艳俗 |
| 高冷/黑金/数码 | 建窑黑釉 | 暗色高级感 |
| 通用 | 官窑月白 | 最素最安全 |

### 5. 文案公式（高点击）

- 数字型：`{N}个提升审美的习惯` `3步泡一盏好茶`
- 悬念型：`为什么宋瓷审美这么高级` `汝窑vs龙泉，怎么选`
- 人群型：`学生党必看` `30岁，学会和自己和解`
- 场景型：`把家装成宋代书房` `人均50的宋式茶馆`
- 标签 3 个以内：`#宋瓷 #新中式 #家居美学`

## 四、批量生产流程

1. 打开生成器 → 选布局/场景/主题/尺寸，或直接带 hash 参数：`生成器.html#layout=list&scene=gonglue&theme=ru&size=34`
2. 点击画布文字直接编辑，或右侧面板批量录入
3. 图片槽点击导入本地照片（自动裁切填充）
4. 导出 PNG（输出宽 ≥1080px，3:4 → 1080×1440，符合平台规范）
5. 同账号系列封面：**固定主题+固定尺寸+换场景换标题**，形成统一品牌辨识度

## 五、避坑清单

- 标题贴边 / 落入底部 15% 盲区 → 用安全区，poster 布局标题放中上部
- 文字占比 >30% → 删 caption，只留标题
- 开片纹太明显 → 透明度 ≤ .06
- 黑釉主题下开片纹用深色（默认值在暗底上不可见）→ 生成器自动反白
- 图片裁切主体 → 导入后拖动调整（slot 支持背景定位）
- 横版当首图 → 除非宽幅风景，否则锁定 3:4
- 印章字太冷僻 → 用单字常用字（天/茶/居/行/物/知）
